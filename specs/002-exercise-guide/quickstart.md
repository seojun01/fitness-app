# Quickstart: 검증 시나리오 — 운동 가이드

**Feature**: `002-exercise-guide` | 계약: [sync-api-delta.md](./contracts/sync-api-delta.md), [guide-content.md](./contracts/guide-content.md) | 모델: [data-model.md](./data-model.md)

기능이 끝까지 동작하는지 확인하는 절차다. 구현 코드는 담지 않는다. 준비와 실행 명령은 [기능 1 quickstart](../001-routine-workout-logging/quickstart.md)와 같다(`npm run dev` → http://localhost:8081).

## 자동 검증

| 명령 | 기대 결과 |
|---|---|
| `npm run lint` | 타입 오류 0, 금지 API 0, 런타임 의존성 0 |
| `npm test` | 인체 모델·보간·투영 단위 테스트, 가이드 콘텐츠 무결성(35개), guideNote 검증·계약·동기화 통과 |
| `npm run test:e2e` | 아래 G1~G12와 axe·320px 점검 통과 |

## 수동 검증

| # | 시나리오 | 기대 결과 | 스토리/요구 |
|---|---|---|---|
| G1 | 가이드 탭 → 스쿼트 | 동작이 반복 재생되고 요점·실수·근육이 보인다. 근육은 그림 강조와 글 목록 둘 다로 보인다 | US1, FR-001·004 |
| G2 | 일시정지 → 재생, 속도 0.5배 | 멈추고 이어서 재생되며 느리게 재생된다 | US1, FR-003 |
| G3 | OS에서 동작 줄이기를 켜고 가이드 열기 | 자동 재생 없이 대표 자세가 보이고 재생 버튼으로만 재생된다 | FR-003 |
| G4 | 세션 진행 중 세트 값 입력 → 종목 "가이드" → 닫기 | 입력 값·스크롤·경과 시간이 그대로다. 탭 2회 이내 | US2, FR-005, SC-001 |
| G5 | 루틴 편집 → 종목 추가 → 종목의 "가이드" → 닫기 → 종목 선택 | 종목 선택 화면으로 돌아와 그대로 고를 수 있다 | US2 |
| G6 | 가이드 탭에서 "하체" 필터, "스쿼트" 검색 | 하체 종목만, 이름이 맞는 종목만 보인다 | US3, FR-006 |
| G7 | 가이드 → 루틴에 추가 → 루틴 선택 | 그 루틴에 종목이 추가된다 | US3, FR-007 |
| G8 | 직접 만든 종목의 가이드 → "가이드 작성" → 요점 2개·근육 저장 → 다시 열기 | 그대로 보인다. 모두 비우면 "아직 가이드가 없어요"로 돌아간다 | US4, FR-011 |
| G9 | 두 기기(페어링)에서 G8 후 다른 기기 확인 | 같은 노트가 보인다 | US4, FR-011 |
| G10 | 기본 종목 가이드 | "가이드 작성"·편집 버튼이 없다 | FR-012 |
| G11 | canvas를 쓸 수 없는 환경(개발자 도구로 막기)에서 가이드 열기 | 그림 대신 동작 설명 글과 텍스트 가이드가 보이고 빈 화면이 없다 | FR-009, SC-004 |
| G12 | 오프라인(앱을 한 번 연 뒤)에서 처음 보는 종목의 가이드 | 글과 동작이 모두 보인다 | FR-010, SC-002 |
| G13 | 기본 종목 이름 변경 / 직접 만든 종목 삭제 후 되돌리기 | 이름을 바꿔도 가이드 유지, 삭제하면 목록에서 빠지고 되돌리면 다시 보인다 | FR-014 |
| G14 | 노트 작성 후 설정 → 내보내기, 전체 삭제 | 내보내기 `version: 2`에 `guideNotes` 포함, 전체 삭제 후 노트가 사라진다 | FR-016 |
| G15 | 기능 1 버전 앱(DB v1)으로 기록한 브라우저에서 새 버전 열기 | 기존 기록이 그대로 있고 가이드 노트를 쓸 수 있다 | 헌법 II, G7 |
| G16 | 320px 폭에서 가이드 목록·보기·편집 | 가로 스크롤 없음, 조작 버튼 44px 이상, axe 위반 0 | 헌법 I |

## 콘텐츠 육안 검토 (자동으로 못 잡는 부분)

- 35개 동작을 한 번씩 보고, 동작이 그 종목처럼 보이는지 체크리스트로 확인한다(관절 각도·가동 범위는 자동으로 검증하지만 "그럴듯함"은 사람이 본다).
- 가이드 화면 하단의 "통증이 있으면 멈추고 전문가와 상의하세요" 안내를 확인한다.
