# Feature Specification: 운동 가이드 (텍스트)

**Feature Branch**: `002-exercise-guide`

**Created**: 2026-11-14

**Status**: Draft (2026-11-14 범위 축소: 텍스트 가이드만)

**Input**: User description: "초보자도 바른 자세를 쉽게 익힐 수 있도록 부위별 운동 GIF 및 3D 모션 가이드를 제공하는 운동 가이드 기능. 사용자는 부위별로 운동 종목을 둘러보고, 각 종목의 동작을 반복 재생되는 애니메이션(GIF)과 여러 각도에서 돌려 볼 수 있는 3D 모션으로 확인하며, 올바른 자세 요점·흔한 실수·주요 자극 근육을 텍스트로 함께 본다. 기존 운동 종목(루틴 편집의 종목 선택, 세션 진행 화면)에서 바로 해당 종목의 가이드를 열 수 있어야 한다. 가이드 미디어는 홈서버에서 제공하며, 오프라인이거나 3D를 지원하지 않는 환경에서는 GIF/정지 이미지와 텍스트로 대체한다."

## Clarifications

### Session 2026-11-14

- Q: 가이드 콘텐츠를 어디서 마련하나? → A: 앱이 직접 만든다(설명 글은 기본 종목마다 앱이 갖춘다).
- Q: 직접 만든 종목에도 가이드를 붙일 수 있나? → A: 설명 글(자세 요점·흔한 실수·주요 자극 근육)만 작성할 수 있고 기기 간에 동기화된다. 이미지·영상 업로드는 하지 않는다.
- Q: (범위 변경) 3D 모션 보기가 필요한가? → A: 필요 없다.
- Q: (범위 변경) 동작 그림(애니메이션)과 근육 지도가 필요한가? → A: 필요 없다. **가이드는 텍스트만** 제공한다. 운동 중 종목 이름 옆 ⓘ(플리크와 같은 자리)로 연다.

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 운동 중 ⓘ로 종목 가이드 보기 (Priority: P1)

사용자는 운동 진행 화면에서 종목 이름 옆 ⓘ를 눌러 그 종목의 자세 요점, 흔한 실수, 주요 자극 근육을 읽고, 닫으면 하던 기록으로 그대로 돌아온다.

**Why this priority**: 초보자가 자세를 확인해야 하는 순간은 운동 중이다. 기록 흐름을 끊지 않고 볼 수 있어야 가치가 생긴다.

**Independent Test**: 진행 화면에서 세트 값을 입력하고 ⓘ로 가이드를 열었다 닫은 뒤, 입력값과 휴식 타이머가 그대로인지 확인한다.

**Acceptance Scenarios**:

1. **Given** 기본 종목의 진행 화면, **When** ⓘ를 누르면, **Then** "자세 요점"(3~5개), "흔한 실수"(2~4개), "주요 자극 근육"(주동근·보조근을 글로 구분)이 대화상자로 보인다.
2. **Given** 열린 가이드, **When** 닫기나 Esc를 누르면, **Then** 진행 화면의 입력값·스크롤·휴식 타이머가 그대로다.
3. **Given** 설명 글이 없는 직접 만든 종목, **When** ⓘ를 누르면, **Then** "아직 가이드가 없어요"와 "가이드 작성"이 보이고 빈 화면이 되지 않는다.
4. 모든 가이드 아래에 "통증이 있으면 멈추고 전문가와 상의하세요" 안내가 있다.

---

### User Story 2 - 종목을 고를 때 가이드 보기 (Priority: P2)

사용자는 루틴 편집·운동 추가의 종목 선택 화면에서 종목마다 가이드를 열어 보고, 닫으면 종목 선택으로 돌아와 고를 수 있다.

**Why this priority**: 낯선 종목을 루틴에 넣을지 판단하는 데 도움이 되지만, 운동 중(US1)보다 덜 급하다.

**Independent Test**: 종목 선택에서 "벤치 프레스 가이드"를 열었다 닫은 뒤 바로 벤치 프레스를 고를 수 있는지 확인한다.

**Acceptance Scenarios**:

1. **Given** 종목 선택 대화상자, **When** 종목의 "가이드"를 누르면, **Then** 가이드가 그 위에 열리고, 닫으면 종목 선택이 그대로 열려 있다.

---

### User Story 3 - 가이드 탭에서 부위별로 둘러보기 (Priority: P2)

사용자는 하단 "가이드" 탭에서 부위(가슴·등·어깨·하체·팔·코어·유산소)를 골라 종목을 훑어보고, 이름으로 찾아 가이드를 열고, 그 종목을 루틴에 추가한다.

**Why this priority**: 계획 단계에서 종목을 익히는 데 유용하지만, 기록 흐름보다 덜 급하다.

**Independent Test**: 가이드 탭에서 "하체"를 고르면 하체 종목만 보이고, 하나를 열어 루틴에 추가할 수 있는지 확인한다.

**Acceptance Scenarios**:

1. **Given** 가이드 탭, **When** 부위를 고르면, **Then** 해당 부위 종목만 이름과 주동근 요약으로 보인다.
2. **Given** 가이드 탭, **When** 이름 일부를 검색하면, **Then** 이름이 맞는 종목만 보인다.
3. **Given** 가이드 화면, **When** "루틴에 추가"에서 루틴을 고르면, **Then** 그 루틴 끝에 종목이 추가된다.

---

### User Story 4 - 직접 만든 종목에 가이드 글 쓰기 (Priority: P2)

사용자는 직접 만든 종목에 자세 요점·흔한 실수·주요 자극 근육을 작성·수정하고, 다른 기기에서도 같은 글이 보인다. 기본 종목의 가이드는 고칠 수 없다.

**Why this priority**: 기본 종목 밖의 운동도 같은 방식으로 정리하게 해 주지만, 기본 가이드(US1)보다 덜 핵심이다.

**Independent Test**: 직접 만든 종목에 요점 2개와 주동근을 저장한 뒤 다시 열어 그대로 보이는지, 다른 기기에서도 보이는지 확인한다.

**Acceptance Scenarios**:

1. **Given** 직접 만든 종목, **When** "가이드 작성"에서 요점·실수·근육을 입력해 저장하면, **Then** 가이드에 그대로 표시된다.
2. **Given** 작성한 가이드, **When** 내용을 모두 비우고 저장하면, **Then** "아직 가이드가 없어요" 상태로 돌아간다.
3. **Given** 홈서버에 연결된 두 기기, **When** 한 기기에서 저장하면, **Then** 다른 기기에서도 같은 글이 보인다.
4. **Given** 기본 종목, **Then** 가이드에 "가이드 작성"·편집 버튼이 없다.

---

### Edge Cases

- 오프라인이면? → 기본 가이드는 앱에 들어 있어 모두 보이고, 직접 쓴 노트는 이 기기에 저장된 최신 내용이 보인다.
- 기본 종목 이름을 바꾸면? → 가이드는 종목 식별자로 연결되어 유지된다. 삭제된 종목은 가이드 탭에서 빠지고, 되돌리면 다시 보인다.
- 같은 노트를 두 기기에서 오프라인으로 동시에 고치면? → 기능 1과 같이 나중 수정이 이긴다.
- 주동근과 보조근에 같은 근육을 고르면? → 안내하고 저장하지 않는다.
- 아주 작은 화면(320px)? → 가로 스크롤 없이 세로로 쌓인다.

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 시스템은 기본 종목 전부(기능 1의 기본 종목 35개)에 대해 "자세 요점"(3~5개), "흔한 실수"(2~4개), "주요 자극 근육"(주동근 1~3개·보조근 0~4개)을 텍스트로 제공해야 한다.
- **FR-002**: 주동근과 보조근은 글로 구분해 보여야 한다(색에만 의존하지 않음).
- **FR-003**: 진행 화면의 종목 이름 옆 ⓘ로 가이드를 열 수 있어야 하며, 닫으면 진행 화면의 상태(입력값, 스크롤, 휴식 타이머)가 그대로 유지되어야 한다.
- **FR-004**: 종목 선택 화면에서 종목마다 가이드를 열 수 있어야 하며, 닫으면 종목 선택으로 돌아와야 한다.
- **FR-005**: 하단 "가이드" 탭에서 부위별로 거르고 이름으로 검색할 수 있어야 한다.
- **FR-006**: 가이드 화면에서 그 종목을 기존 루틴 끝에 추가할 수 있어야 한다.
- **FR-007**: 사용자는 직접 만든 종목에 자세 요점·흔한 실수·주요 자극 근육을 작성·수정·삭제할 수 있어야 하며, 이 노트는 기록과 같은 방식으로 기기에 즉시 저장되고 홈서버를 통해 다른 기기와 동기화되어야 한다.
- **FR-008**: 기본 종목의 가이드는 읽기 전용이어야 한다.
- **FR-009**: 노트 입력은 검증되어야 한다: 요점·실수는 각각 최대 10개, 항목당 1~200자, 근육은 정해진 목록에서 각 최대 6개, 주동근과 보조근은 겹칠 수 없다.
- **FR-010**: 가이드는 종목 식별자로 연결되어 이름을 바꿔도 유지되고, 삭제된 종목은 가이드 탭에서 빠져야 한다.
- **FR-011**: 기본 가이드는 네트워크 없이도 항상 보여야 한다.
- **FR-012**: 직접 쓴 노트는 데이터 내보내기에 포함되고 전체 삭제 시 함께 지워져야 한다.
- **FR-013**: 가이드 화면에는 "통증이 있으면 멈추고 전문가와 상의하세요" 안내가 있어야 한다.

### Key Entities

- **기본 가이드(Built-in Guide)**: 앱에 들어 있는 읽기 전용 자료. 기본 종목 식별자, 자세 요점, 흔한 실수, 주동근·보조근.
- **가이드 노트(Guide Note)**: 직접 만든 종목에 사용자가 쓴 글. 종목 식별자, 요점, 실수, 주동근·보조근. 동기화·삭제 표시·내보내기 대상.
- **근육(Muscle)**: 정해진 근육 17종(대흉근, 광배근, 승모근, 능형근, 전면·측면·후면 삼각근, 이두근, 삼두근, 전완근, 복직근, 복사근, 척추기립근, 둔근, 대퇴사두근, 햄스트링, 종아리).

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 운동 중 가이드를 열고 닫아 기록으로 돌아오기까지 탭 2회면 되고, 입력값과 타이머는 100% 유지된다.
- **SC-002**: 기본 종목 100%가 세 가지 텍스트 항목을 모두 갖춘다.
- **SC-003**: 가이드는 오프라인에서도 체감 지연 없이(1초 이내) 열린다.
- **SC-004**: 처음 보는 기본 종목의 가이드를 읽은 뒤, 소유자가 그 종목의 핵심 자세 요점을 안내 없이 설명할 수 있다.

## Assumptions

- 기능 1·3의 종목·루틴·진행 화면과 홈서버 동기화가 이미 있다.
- 기본 가이드 문구는 일반적인 근력 운동 지도 상식을 바탕으로 앱이 직접 작성한다. 의학적 조언이 아니다.
- 동작 그림·애니메이션·3D·근육 지도·사진·영상은 범위 밖이다(사용자 결정).
- 화면 문구는 한국어만 지원한다.
