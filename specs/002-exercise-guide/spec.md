# Feature Specification: 운동 가이드 (부위별 동작 애니메이션)

**Feature Branch**: `002-exercise-guide`

**Created**: 2026-11-14

**Status**: Draft

**Input**: User description: "초보자도 바른 자세를 쉽게 익힐 수 있도록 부위별 운동 GIF 및 3D 모션 가이드를 제공하는 운동 가이드 기능. 사용자는 부위별로 운동 종목을 둘러보고, 각 종목의 동작을 반복 재생되는 애니메이션(GIF)과 여러 각도에서 돌려 볼 수 있는 3D 모션으로 확인하며, 올바른 자세 요점·흔한 실수·주요 자극 근육을 텍스트로 함께 본다. 기존 운동 종목(루틴 편집의 종목 선택, 세션 진행 화면)에서 바로 해당 종목의 가이드를 열 수 있어야 한다. 가이드 미디어는 홈서버에서 제공하며, 오프라인이거나 3D를 지원하지 않는 환경에서는 GIF/정지 이미지와 텍스트로 대체한다."

## Clarifications

### Session 2026-11-14

- Q: 가이드 콘텐츠(동작 미디어와 설명 글)를 어디서 마련하나? → A: 앱이 직접 만든다. 설명 글은 앱이 기본 종목마다 갖추고, 동작은 앱에 내장된 단순한 인체 모델(관절·뼈대)을 움직여 2D 반복 애니메이션으로 보여 준다. 외부 GIF·3D 파일은 쓰지 않는다.
- Q: (범위 변경) 3D 모션 보기가 필요한가? → A: 필요 없다. 동작은 종목마다 정해진 시점(대개 측면)의 2D 반복 애니메이션으로만 보여 준다. 3D 보기·시점 돌리기는 범위에서 뺀다.
- Q: 직접 만든 종목에도 가이드를 붙일 수 있나? → A: 설명 글(자세 요점·흔한 실수·주요 자극 근육)만 작성할 수 있고, 기록처럼 기기 간에 동기화된다. 이미지·영상 업로드는 하지 않는다.

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 종목 가이드 보기 (Priority: P1)

사용자는 한 종목의 가이드를 열어 반복 재생되는 동작 애니메이션과 함께 올바른 자세 요점, 흔한 실수, 주요 자극 근육을 읽는다.

**Why this priority**: 가이드 화면 자체가 이 기능의 핵심 가치(바른 자세 학습)이며, 다른 진입 경로는 모두 이 화면을 전제로 한다.

**Independent Test**: 기본 종목 하나(예: 스쿼트)의 가이드를 열어 애니메이션이 반복 재생되고 세 가지 텍스트 항목이 모두 보이면 단독으로 검증된다.

**Acceptance Scenarios**:

1. **Given** 기본 종목, **When** 가이드를 열면, **Then** 인체 모델의 동작 애니메이션이 자동으로 반복 재생되고 "자세 요점", "흔한 실수", "주요 자극 근육"이 표시된다.
2. **Given** 재생 중인 애니메이션, **When** 일시정지를 누르면, **Then** 멈추고 다시 누르면 이어서 재생된다.
3. **Given** 동작 줄이기(reduced motion) 설정을 켠 기기, **When** 가이드를 열면, **Then** 애니메이션은 자동 재생되지 않고 동작의 대표 자세(정지 화면)와 재생 버튼이 보인다.
4. **Given** 애니메이션, **When** 주요 자극 근육을 보면, **Then** 인체 모델에서 해당 부위가 색과 함께 글자 목록으로도 구분되어 보인다.

---

### User Story 2 - 운동 중·루틴 편집 중 바로 가이드 열기 (Priority: P1)

사용자는 세션 진행 화면의 각 종목과 루틴 편집의 종목 선택 화면에서 버튼 한 번으로 그 종목의 가이드를 열고, 닫으면 하던 화면으로 그대로 돌아온다.

**Why this priority**: 초보자가 자세를 확인해야 하는 순간은 운동 중이다. 기록 흐름을 끊지 않고 가이드를 볼 수 있어야 가치가 생긴다.

**Independent Test**: 세션 진행 중 종목의 가이드를 열었다 닫은 뒤, 입력하던 세트 값과 경과 시간이 그대로인지 확인한다.

**Acceptance Scenarios**:

1. **Given** 진행 중인 세션, **When** 종목의 "가이드" 버튼을 누르면, **Then** 그 종목의 가이드가 열리고, 닫으면 세션 화면의 입력 값과 스크롤 위치가 유지된다.
2. **Given** 루틴 편집의 종목 선택 화면, **When** 종목의 "가이드"를 누르면, **Then** 가이드가 열리고, 닫으면 종목 선택 화면으로 돌아와 종목을 고를 수 있다.
3. **Given** 설명 글이 아직 없는 직접 만든 종목, **When** 가이드를 열면, **Then** "아직 가이드가 없어요"와 "가이드 작성" 버튼이 보이고 빈 화면이 되지 않는다.

---

### User Story 3 - 부위별로 가이드 둘러보기 (Priority: P2)

사용자는 가이드 목록에서 부위(가슴·등·어깨·하체·팔·코어·유산소)를 골라 종목들을 훑어보고, 이름으로 찾아 원하는 가이드를 연다.

**Why this priority**: 운동 계획 단계에서 새로운 종목을 익히는 데 유용하지만, 운동 중 진입(US2)보다 덜 급하다.

**Independent Test**: 가이드 목록에서 "하체"를 고르면 하체 종목만 보이고, 그중 하나를 열 수 있는지 확인한다.

**Acceptance Scenarios**:

1. **Given** 가이드 목록, **When** 부위를 선택하면, **Then** 해당 부위 종목만 동작 미리보기(정지 자세)와 이름으로 보인다.
2. **Given** 가이드 목록, **When** 이름 일부를 검색하면, **Then** 이름이 맞는 종목만 보인다.
3. **Given** 가이드 화면, **When** "루틴에 추가"에서 루틴을 고르면, **Then** 그 루틴에 종목이 추가된다.

---

### User Story 4 - 직접 만든 종목에 가이드 글 쓰기 (Priority: P2)

사용자는 직접 만든 종목에 자세 요점·흔한 실수·주요 자극 근육을 작성하고 고칠 수 있으며, 다른 기기에서도 같은 글이 보인다.

**Why this priority**: 기본 종목 밖의 운동도 같은 방식으로 정리할 수 있게 해 주지만, 기본 종목의 가이드(US1)보다는 덜 핵심이다.

**Independent Test**: 직접 만든 종목에 자세 요점 2개와 자극 근육을 저장한 뒤 다시 열어 그대로 보이는지, 연결된 다른 기기에서도 보이는지 확인한다.

**Acceptance Scenarios**:

1. **Given** 직접 만든 종목, **When** "가이드 작성"에서 요점·실수·근육을 입력해 저장하면, **Then** 가이드 화면에 그대로 표시된다.
2. **Given** 작성한 가이드, **When** 내용을 고치거나 비우면, **Then** 변경이 저장되고 모두 비우면 "아직 가이드가 없어요" 상태로 돌아간다.
3. **Given** 홈서버에 연결된 두 기기, **When** 한 기기에서 가이드 글을 저장하면, **Then** 다른 기기에서도 같은 글이 보인다.
4. **Given** 기본 종목, **When** 가이드를 보면, **Then** 기본 가이드는 고칠 수 없고 "가이드 작성" 버튼이 없다.

---

### Edge Cases

- 오프라인이면? → 기본 가이드(글·동작)는 앱에 들어 있어 오프라인에서도 모두 보인다. 직접 쓴 가이드 글은 이 기기에 저장된 최신 내용이 보인다.
- 직접 만든 종목에는 동작 애니메이션이 없다. → 동작 자리에 그 종목 부위의 인체 모델 정지 그림(해당 부위 강조)과 "동작 애니메이션은 기본 종목에만 있어요" 안내가 보인다.
- 사용자가 기본 종목의 이름을 바꾸면? → 가이드는 종목 고유 식별자로 연결되어 유지된다. 기본 종목을 삭제하면 가이드 목록에서 빠지고, 되돌리면 다시 보인다.
- 직접 만든 종목을 삭제하면? → 그 가이드 글도 목록에서 빠지고, 종목을 되돌리면 글도 다시 보인다.
- 같은 가이드 글을 두 기기에서 오프라인으로 동시에 고치면? → 기능 1과 같이 나중 수정이 이긴다.
- 아주 작은 화면(320px)에서는? → 동작 그림과 텍스트가 세로로 쌓이고 가로 스크롤이 생기지 않는다.

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 시스템은 기본 종목 전부(기능 1의 기본 종목 목록)에 대해 반복 재생되는 동작 애니메이션, "자세 요점"(3~5개), "흔한 실수"(2~4개), "주요 자극 근육"(주동근·보조근)을 제공해야 한다.
- **FR-002**: 동작 애니메이션은 앱에 내장된 하나의 단순한 인체 모델(머리·몸통·팔·다리 관절)을 움직여 그려야 하며, 외부 이미지·영상 파일에 의존하지 않아야 한다.
- **FR-003**: 사용자는 애니메이션을 일시정지·재생하고 재생 속도(0.5배·1배)를 바꿀 수 있어야 하며, 기기의 동작 줄이기 설정이 켜져 있으면 자동 재생하지 않고 대표 자세를 정지 화면으로 보여야 한다.
- **FR-004**: 주요 자극 근육은 글자 목록과 함께 인체 모델에서 해당 부위 강조로도 보여야 하며, 색에만 의존해서는 안 된다(주동근·보조근을 글로 구분).
- **FR-005**: 사용자는 세션 진행 화면과 종목 선택 화면에서 버튼 한 번으로 해당 종목의 가이드를 열 수 있어야 하며, 닫으면 원래 화면의 상태(입력 값, 스크롤, 진행 중인 기록)가 그대로 유지되어야 한다.
- **FR-006**: 사용자는 가이드 목록을 부위별로 거르고 이름으로 검색할 수 있어야 한다.
- **FR-007**: 사용자는 가이드 화면에서 해당 종목을 기존 루틴에 추가할 수 있어야 한다.
- **FR-008**: 동작은 종목마다 동작이 가장 잘 보이는 하나의 정해진 시점(정면·측면 등)에서 보여 주어야 한다.
- **FR-009**: 동작 그림을 그릴 수 없는 환경에서는 그림 대신 동작을 설명하는 글과 텍스트 가이드로 대체해야 하며, 오류로 화면이 비어서는 안 된다.
- **FR-010**: 기본 가이드(글과 동작)는 네트워크 없이도 항상 보여야 한다.
- **FR-011**: 사용자는 직접 만든 종목에 자세 요점·흔한 실수·주요 자극 근육을 작성·수정·삭제할 수 있어야 하며, 이 글은 기록과 같은 방식으로 기기에 즉시 저장되고 홈서버를 통해 다른 기기와 동기화되어야 한다.
- **FR-012**: 기본 종목의 가이드는 읽기 전용이어야 한다.
- **FR-013**: 직접 쓴 가이드 글의 입력은 검증되어야 한다: 요점·실수는 각각 최대 10개, 항목당 1~200자, 근육은 미리 정한 근육 목록에서 고른다.
- **FR-014**: 가이드는 종목의 고유 식별자로 연결되어, 종목 이름을 바꿔도 유지되어야 하고 삭제된 종목의 가이드는 목록에서 빠져야 한다.
- **FR-015**: 동작 그림에는 동작을 설명하는 대체 텍스트가 있어야 하며, 재생·속도·시점 조작은 키보드와 화면 낭독기로 사용할 수 있어야 한다.
- **FR-016**: 직접 쓴 가이드 글은 기능 1의 데이터 내보내기에 포함되고, 전체 삭제 시 함께 지워져야 한다.

### Key Entities

- **기본 가이드(Built-in Guide)**: 앱에 들어 있는 읽기 전용 자료. 기본 종목 식별자, 자세 요점 목록, 흔한 실수 목록, 주동근·보조근, 동작 정의(인체 모델의 자세 키프레임과 반복 주기), 대표 자세, 대체 텍스트를 가진다.
- **사용자 가이드 노트(Custom Guide Note)**: 직접 만든 종목에 사용자가 쓴 가이드 글. 종목 식별자, 자세 요점 목록, 흔한 실수 목록, 주동근·보조근을 가지며 기능 1의 레코드처럼 동기화·삭제 표시·내보내기 대상이다.
- **운동 종목(Exercise)**: 기능 1에서 정의한 종목. 기본 가이드 또는 사용자 가이드 노트와 1:0..1 관계이며 부위로 분류된다.
- **근육(Muscle)**: 미리 정한 근육 목록(예: 대흉근, 광배근, 삼각근, 대퇴사두근, 햄스트링, 둔근, 이두근, 삼두근, 복근, 종아리 등). 인체 모델의 강조 부위와 대응한다.
- **인체 모델(Body Model)**: 모든 동작이 공유하는 단순한 관절 구조. 정지 그림과 애니메이션이 같은 동작 정의를 쓴다.

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 운동 중 사용자는 세션 화면에서 가이드를 열고 닫아 기록으로 돌아오기까지 탭 2회 이내로 할 수 있고, 그동안 입력하던 값이 100% 유지된다.
- **SC-002**: 가이드를 열면 텍스트와 동작 애니메이션이 체감 지연 없이(1초 이내) 보이기 시작하며, 이는 오프라인에서도 같다.
- **SC-003**: 기본 종목 100%가 동작 애니메이션과 세 가지 텍스트 항목을 모두 갖춘다.
- **SC-004**: 동작 그림을 그릴 수 없는 환경에서 가이드를 열었을 때 빈 화면이나 오류 화면이 나오는 경우가 0건이다.
- **SC-005**: 애니메이션은 중급 모바일 기기에서 끊김 없이(눈에 띄는 멈춤 없이) 반복 재생된다.
- **SC-006**: 처음 보는 기본 종목의 가이드를 본 뒤, 소유자가 그 종목의 핵심 자세 요점을 안내 없이 설명할 수 있다.

## Assumptions

- 기능 1(운동 루틴 관리 및 세트 기록)의 운동 종목·루틴·세션 화면과 홈서버 동기화가 이미 있다.
- 사용자의 표현 "GIF"는 "반복 재생되는 동작 애니메이션"으로 해석한다. 실제 GIF 파일은 만들지 않는다.
- 기본 가이드는 앱과 함께 배포되어 홈서버가 앱 파일로 제공하므로 별도의 미디어 서버나 외부 서비스가 필요 없다.
- 인체 모델은 사실적인 사람이 아니라 단순한 형태(마네킹·막대 인형 수준)이며, 목적은 관절 각도·움직임 경로·자세 이해다.
- 기본 가이드 문구는 일반적인 근력 운동 지도 상식을 바탕으로 앱이 직접 작성한다. 의학적 조언이 아니며, 가이드 화면에 "통증이 있으면 멈추고 전문가와 상의하세요" 안내를 둔다.
- 화면 문구는 한국어만 지원한다.
- 3D 보기·시점 돌리기, 실사 동영상·음성 안내·카메라 자세 교정(AI 분석)·사용자 미디어 업로드·기본 가이드 수정은 범위 밖이다.
- 직접 만든 종목에는 동작 애니메이션을 만들 수 없다(이번 범위).
- 성장 차트·통계(기능 3)와 HealthKit 연동(기능 4)은 범위 밖이다.
