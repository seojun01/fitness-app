## 자동 검증

| 명령 | 기대 결과 |

| `npm run lint` | 타입 오류 0, 금지 API 0, 런타임 의존성 0 |

| `npm run test:e2e` | 아래 F1~F14와 기존 기능 1 시나리오, axe(두 테마)·320px 통과 |
