# Research: 운동 흐름 개편

**Feature**: `003-workout-flow-redesign` | **Date**: 2026-11-14 | **Plan**: [plan.md](./plan.md)

기능 1의 결정(R1~R19)은 그대로 유효하다. 각 항목은 결정 / 근거 / 대안 순서다.

### W1. 진행 화면 구조: 한 종목씩, URL 에 종목 번호

- **결정**: `#/session/:index`(0부터)로 지금 보는 종목을 나타낸다. `#/session`은 마지막으로 본 종목(없으면 0)으로 연다. 종목을 옮길 때는 종목 영역만 다시 그리고, 상단(경과 시간·진행 점)과 하단 휴식 타이머는 유지한다. 해시가 바뀌어도 화면 전체를 다시 만들지 않는다.
- **근거**: 새로고침·뒤로 가기에도 위치가 유지된다. 타이머와 경과 시간이 깜빡이지 않는다.
- **대안**: 가로 스와이프 캐러셀은 접근성(키보드·화면 낭독기)과 실수 스와이프 문제로 기각했다. 버튼과 진행 점으로 충분하다.

### W2. 휴식 타이머: 끝나는 시각 기준 상태 기계

- **결정**: 상태는 `idle(base)`, `running(endsAt)`, `paused(remainingMs)`, `done`이다. 남은 시간은 화면을 갱신할 때마다 `endsAt − now`로 계산한다. 화면 갱신은 250ms 간격이다.
  - 상태를 `localStorage`(`fitness.restTimer`)에 저장해 새로고침 후에도 잇는다(FR-010).
  - 세트 완료(완료 표시를 켤 때만)로 `start(base)`를 호출한다.
  - −/+는 진행 중이면 `endsAt`을 ±15초 옮기고, 멈춰 있으면 `base`를 바꿔 설정에 저장한다(15~600초).
  - 0이 되면 `done`이 되고, 진동 `[200, 100, 200]`과 `role="status"`의 "휴식 끝"으로 알린다.
- **근거**: `setInterval` 횟수를 세면 백그라운드 탭에서 느려진다(브라우저가 타이머를 늦춘다). 시각 기준이면 오차가 1초 이내다(SC-003).
- **대안**: Service Worker 알림은 앱이 닫혀 있을 때 알림이 필요해야 의미가 있는데, 스펙 범위 밖이라 기각했다.

### W3. 지난번 대비 기준

- **결정**:
  - **지난번 값**은 이 세션을 제외한 완료 세션 중 같은 종목을 포함한 가장 최근 세션에서, 그 종목 항목들의 완료 세트 합계다(prefill R13과 같은 세션 선택 규칙).
  - **이번 값**은 지금 보는 항목의 완료 세트 합계다.
  - 측정은 지난번·이번의 모든 세트 무게가 0(또는 맨몸 종목)이면 "횟수"(reps 합), 아니면 "볼륨"(무게×횟수 합)이다.
  - 차이 표시는 `▼(지난번 − 이번)`(아직 못 미침), `▲(이번 − 지난번)`(넘음), 같으면 "지난번과 같아요"다.
  - 화면 낭독기용 문구는 "지난번까지 480kg 남음" 또는 "지난번보다 20kg 많음"으로 따로 둔다.
- **근거**: 플리크 스크린숏의 "횟수 0회 ▼26회"와 "볼륨 0kg ▼960kg" 표기와 의미가 같다.

### W4. 종목 기록 지표

- **결정**: 같은 종목의 완료(삭제 안 된) 세션의 완료 세트를 대상으로 계산한다.
  - **추정 1RM 최고**: 세트마다 `w × (1 + r/30)`(r=1이면 w), 무게 0 세트는 제외한다. 최댓값을 소수 첫째 자리에서 반올림한다.
  - **최고 무게**: 세트 무게의 최댓값이다.
  - **누적 볼륨**: 모든 세트의 무게×횟수 합이다.
  - **최근 기록**: 최신 세션 2개의 날짜와 세트 목록이다.
  - 맨몸 종목은 1RM과 최고 무게 대신 "최다 횟수"와 "누적 횟수"를 보여 준다.
- **근거**: 엡리 공식은 가장 널리 쓰이는 추정식이다. 스펙 가정대로 "추정"이라고 표시한다.

### W5. 메모·휴식 시간의 저장 위치

- **결정**:
  - 메모는 `Exercise.memo`(선택 필드)다. 입력 후 400ms 동안 입력이 없으면 저장하고, 화면을 떠날 때는 바로 저장한다. 저장은 기존 `saveRecords`로 하므로 새 version이 발급되고 동기화된다.
  - 휴식 시간은 `Settings.restSeconds`(선택, 기본 60)다.
- **근거**:
  - 메모는 기구 설정 같은 종목 단위 정보라 세션이 아니라 종목에 둔다.
  - 새 레코드 종류를 만드는 대신 선택 필드로 두면 서버·IndexedDB 스키마가 바뀌지 않는다.
- **알려진 한계**: 종목 이름 수정과 메모 수정이 서로 다른 기기에서 오프라인으로 동시에 일어나면 LWW로 한쪽이 진다. 단일 사용자라 드물어 허용한다.
- **디바운스 이유**: 키 입력마다 version을 발급하면 동기화가 잦아진다. 400ms로 묶는다.

### W6. 테마

- **결정**:
  - `<html data-theme="dark|light">`로 고른다. 시스템 설정을 따를 때는 속성을 빼고 `prefers-color-scheme`를 쓴다.
  - 기본값은 `dark`이고, `localStorage`(`fitness.theme`)에 저장한다.
  - 저장값을 첫 화면 전에 적용해 깜빡임이 없도록 `index.html`에 작은 인라인 스크립트를 둔다. 기존 CSP가 없어서 가능하다. 인라인 스크립트는 textContent·innerHTML 금지 규칙과 무관하다.
- **색**:
  - 어두운 테마는 플리크풍으로 배경 #0f0f10, 카드 #1c1c1e, 강조 #e5512f(주황빨강), 부위 글자 #4ade80(초록)이다.
  - 버튼 글자는 강조 위에 흰색을 쓴다. 대비 4.5:1을 만족하도록 강조 진하기를 axe로 확인해 조정한다.

### W7. 루틴 카드 요약과 정렬

- **결정**:
  - **부위**: 루틴 항목의 종목(삭제 안 된 것)의 `bodyPart`를 루틴 순서대로 중복 없이 한국어로 나열한다. 최대 3개 뒤는 "외 N"으로 줄인다.
  - **마지막 수행일**: `routineId`가 같은 완료 세션의 최신 `endedAt`이다. 기기 시간대 기준 날짜 차이로 오늘·어제·N일 전을 쓰고, 30일을 넘으면 날짜로 표시한다.
  - **정렬**: "최근"은 마지막 수행일 내림차순이고, 기록이 없는 루틴은 뒤에서 만든 순서다. "이름"은 한국어 정렬이다. 선택은 `localStorage`에 둔다.

### W8. 앱 셸 변경

- **결정**: `Screen`에 두 옵션을 더한다.
  - `back?: string`: 상단 왼쪽에 "‹" 뒤로 링크를 둔다(`aria-label="뒤로"`).
  - `focus?: boolean`: 하단 탭을 숨기고 본문 아래 여백을 하단 고정 바에 맞춘다.
- 진행 화면은 `focus`, 루틴 상세는 `back`을 쓴다. 메인의 하단 고정 버튼은 탭 위에 놓는다.

### W9. 기존 테스트 영향

- **결정**:
  - 진행 화면의 접근 이름은 유지한다(`<종목> N세트 무게/횟수/완료`, `세션 종료`, `<종목> 세트 추가`). 기존 E2E가 최대한 그대로 돌게 하기 위해서다.
  - 메인의 "새 루틴" → "+ 추가", "빈 세션 시작" → "자유운동", 루틴 편집 진입(카드 → 상세 → 편집)은 테스트 도우미를 고쳐 맞춘다.
  - 여러 종목을 한 화면에서 입력하던 테스트는 "다음 운동" 이동을 넣는다.
