# Quickstart: 성장 차트·통계 확인

## 자동 검증

```bash
npm run lint          # 타입·금지 규칙
npm test              # shared/tests/growth.test.ts 포함 (집계 값 = 직접 계산한 값)
npm run test:e2e      # e2e/stats.spec.ts, a11y(통계·종목 차트, 두 테마·320px)
```

## 수동 시나리오 (개발 서버)

1. `FITNESS_DEV=1 FITNESS_DB=/tmp/fitness-dev/dev.db npm run dev` → `http://localhost:8081`
2. **US1**: 벤치 프레스를 60kg×5, 65kg×5, 70kg×5로 서로 다른 날 세 번 기록한다(`scripts/seed-sessions.mjs` 또는 직접 입력). 통계 → 종목 찾기 → 벤치 프레스 → 점 3개가 오른쪽 위로 이어지고, PR 최고 무게 "70kg · (마지막 날짜)"가 보인다. ←/→로 점을 옮기면 아래 글이 바뀐다.
3. **US2**: 이번 주 2회, 지난주 1회 기록 → "4주"에서 "운동 3회", 주별 막대 마지막 두 개가 1·2.
4. **US3**: 가슴 6세트·하체 3세트만 있는 기간 → 가슴 67%, 하체 33%, 나머지 0세트가 아래에 있다.
5. **US4**: 달력에서 운동한 날에 점이 보이고, 누르면 그 세션 상세(여럿이면 그날 목록)가 열린다.
6. **US5**: 운동 진행 → "기록" 펼치기 → "차트 보기" → 차트 대화상자 → 닫으면 입력값·휴식 타이머가 그대로다.
7. 설정에서 lb로 바꾸면 모든 무게가 lb로 보인다. 비행기 모드(오프라인)에서도 통계가 보인다.
8. **SC-001**: `node scripts/seed-sessions.mjs`로 500세션을 넣고 통계 탭·종목 차트가 1초 안에 뜨는지 본다.
