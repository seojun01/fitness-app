# UI Contract: 성장 차트·통계

E2E 테스트가 기대는 경로, 접근 가능한 이름(역할·라벨)이다. 서버 API는 바뀌지 않는다.

## 경로

| 경로 | 화면 | 탭 |
|---|---|---|
| `#/stats` | 통계 대시보드 | 통계 |
| `#/stats/exercise/:id` | 종목 차트 | 통계 |
| `#/stats/day/:yyyy-mm-dd` | 그날 세션 목록 (세션 2개 이상인 날) | 통계 |

하단 탭(navigation "주 메뉴")은 링크 5개다: 루틴, 기록, **통계**, 가이드, 설정.

## 통계 대시보드 (`#/stats`, 제목 "통계")

| 요소 | 역할·이름 |
|---|---|
| 기간 선택 | radiogroup "기간": 라디오 "4주", "3개월", "1년", "전체" |
| 요약 | region "기간 요약". 항목 "운동 N회", "총 볼륨 X kg", "운동 시간 H시간 M분", 증감 글 "지난 기간보다 2회 늘었어요"(▲/▼ 기호에 글이 함께) |
| 막대 차트 | region "주별 운동" (월별이면 "월별 운동"). img 차트 2개("운동 횟수", "볼륨"), "표로 보기" details 안에 table |
| 부위 비중 | region "부위별 비중". 부위마다 button "가슴 6세트 67%" → 그 부위 종목 목록(list) 펼침, 종목은 link "벤치 프레스 차트" |
| 달력 | region "운동 달력". button "이전 달"/"다음 달", heading "2026년 11월", "이번 달 운동 N일", 날짜 button "11월 3일, 운동 1회" (운동 안 한 날은 "11월 4일"이고 비활성) |
| 종목 찾기 | searchbox "종목 차트 찾기", list "기록이 있는 종목" (최근 순), 항목 link "<종목> 차트" |
| 빈 상태 | "운동을 기록하면 여기에 통계가 쌓여요" |

## 종목 차트 (`#/stats/exercise/:id` 또는 대화상자 "<종목> 차트")

| 요소 | 역할·이름 |
|---|---|
| 기간 선택 | radiogroup "기간" (대시보드와 같은 값을 공유) |
| 지표 선택 | radiogroup "지표": "추정 1RM", "최고 무게", "세션 볼륨" (맨몸: "세션 총 횟수", "최다 횟수") |
| 차트 | img, 이름은 요약 문장. 차트를 감싼 group "점 고르기"(tabindex 0, ←/→) |
| 고른 점 | status: "11월 3일 · 추정 1RM 87.5kg · 80kg×5, 80kg×4" |
| 표 | details "표로 보기" 안의 table (날짜, 지표 값) |
| PR | region "개인 최고 기록": "추정 1RM 87.5kg · 11월 3일" 등 |
| 안내 | 점 1개: "기록이 쌓이면 추이가 보여요", 0개: "아직 기록이 없어요", 묶음: "기록이 많아 주별 최고값으로 보여요" |

## 진입점 (FR-011)

| 위치 | 요소 | 동작 |
|---|---|---|
| 세션 상세 종목 카드 | link "<종목> 차트" | `#/stats/exercise/:id` |
| 종목 이력 화면 | link "차트 보기" | `#/stats/exercise/:id` |
| 진행 화면 "기록" 펼침 | button "차트 보기" | dialog "<종목> 차트" 열기. 닫기 button "닫기", Esc. 진행 화면 그대로 |
