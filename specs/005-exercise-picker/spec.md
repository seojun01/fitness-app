# Feature Specification: 종목 선택 개편과 기본 종목 확장

**Feature Branch**: `005-exercise-picker`

**Created**: 2026-11-15

**Status**: Draft

**Input**: User description: 루틴에 운동을 추가하는 화면을 플리크처럼 바꾼다(스크린숏 3장). 검색창, 분류 필터(전체·좋아하는·자주하는·최근·커스텀), 근육 부위 필터(가슴·등·어깨·삼두·이두·복근·둔근·햄스트링·대퇴사두·승모·종아리 …), 장비 필터(맨몸·유산소·덤벨·바벨·스미스머신·밴드·머신·케이블 …), "커스텀 운동 추가", 종목마다 좋아요·이름·자극 부위·더보기, 여러 종목을 골라 "+ N 운동 추가"로 한 번에 넣기, 선택 초기화, 맨 위로. 그리고 기본 등록된 운동 종목을 더 추가한다.

## Clarifications

### Session 2026-11-15

- Q: 종목 이미지(일러스트)도 넣나? → A: 아니다. 앞서 동작 그림은 필요 없다고 정했으므로 이미지 없이 이름·자극 부위만 보여 준다.
- Q: 기본 종목을 얼마나 늘리나? → A: 장비별 변형(스미스 머신·머신·케이블·덤벨·밴드·케틀벨 등)을 중심으로 약 90개까지 늘리고, 새 종목에도 기존 규칙대로 텍스트 가이드를 붙인다(기능 2 FR-001 유지).

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 여러 종목을 골라 한 번에 추가 (Priority: P1)

사용자는 루틴 편집·루틴 상세·운동 진행 화면에서 종목 추가를 누르면 전체 화면 종목 선택이 열린다. 종목을 눌러 여러 개를 고르면(체크 표시) 아래에 "+ N 운동 추가"가 나타나고, 누르면 고른 순서대로 한 번에 추가된다.

**Why this priority**: 루틴을 만들 때 종목을 하나씩 추가하느라 선택 화면을 여러 번 여닫는 것이 가장 불편하다.

**Independent Test**: 루틴 편집에서 종목 3개를 골라 "+ 3 운동 추가"를 누르면 세 종목이 고른 순서대로 루틴에 들어가는지 확인한다.

**Acceptance Scenarios**:

1. **Given** 종목 선택, **When** 종목을 누르면, **Then** 체크 표시가 생기고 아래에 "+ 1 운동 추가"가 보인다. 다시 누르면 선택이 풀린다.
2. **Given** 3개 선택, **When** "+ 3 운동 추가"를 누르면, **Then** 선택 화면이 닫히고 고른 순서대로 추가된다(루틴 편집·루틴 상세·진행 화면 모두).
3. **Given** 선택이 있음, **When** 선택 초기화(↺)를 누르면, **Then** 모든 선택이 풀린다.
4. **Given** 선택 화면, **When** 뒤로(‹)나 Esc를 누르면, **Then** 아무것도 추가하지 않고 닫힌다.
5. **Given** 진행 화면에서 여러 종목을 추가함, **Then** 추가된 첫 종목으로 이동한다.

---

### User Story 2 - 검색과 세 줄 필터 (Priority: P1)

사용자는 이름으로 찾거나, 분류(전체·좋아하는·자주하는·최근·커스텀), 근육 부위, 장비 필터를 조합해 종목을 좁힌다.

**Why this priority**: 종목이 90개 가까이 되면 필터 없이는 찾기 어렵다.

**Independent Test**: 부위 "이두"와 장비 "케이블"을 고르면 케이블 컬만 보이는지 확인한다.

**Acceptance Scenarios**:

1. **Given** 필터 세 줄, **Then** 줄마다 하나씩 고를 수 있고(기본 "전체"), 고른 것이 강조된다. 세 필터와 검색어는 함께 적용된다(그리고 조건).
2. **Given** 분류 "좋아하는", **Then** 좋아요한 종목만 보인다. "자주하는"은 완료한 운동에 많이 쓴 순서, "최근"은 마지막으로 쓴 날짜가 최근인 순서, "커스텀"은 직접 만든 종목만 보인다.
3. **Given** 근육 부위 필터, **Then** 그 근육을 주로 쓰거나 보조로 쓰는 종목이 보인다(예: "삼두"에 벤치 프레스 포함).
4. **Given** 결과가 없음, **Then** "맞는 종목이 없어요"와 커스텀 운동 추가 안내가 보인다.
5. 각 종목 줄에는 이름 아래에 자극 부위(최대 2개, 예: "등, 이두")가 보인다.

---

### User Story 3 - 좋아요와 종목 메뉴 (Priority: P2)

사용자는 하트로 자주 쓰는 종목을 표시하고, 더보기(⋯)에서 가이드·이력·이름 수정·삭제를 한다.

**Why this priority**: 즐겨 찾기는 반복 사용을 빠르게 해 주지만, 고르기·찾기(US1·US2)보다 덜 핵심이다.

**Independent Test**: 종목에 하트를 누르고 "좋아하는" 필터에서 보이는지, 다른 기기에서도 하트가 보이는지 확인한다.

**Acceptance Scenarios**:

1. **Given** 종목 줄, **When** 하트를 누르면, **Then** 좋아요가 켜지고 꺼지며, 기록처럼 저장·동기화된다.
2. **Given** 더보기(⋯), **Then** "가이드", "이력", "이름 수정", "삭제"를 고를 수 있다(삭제는 되돌리기 제공).
3. 하트를 누르거나 메뉴를 열어도 종목 선택 상태는 바뀌지 않는다.

---

### User Story 4 - 커스텀 운동 추가 (Priority: P2)

사용자는 "커스텀 운동 추가"(또는 위쪽 + 버튼)로 이름·부위·장비를 정해 종목을 만들고, 만든 종목은 바로 선택된다.

**Why this priority**: 기본 종목에 없는 운동을 쓸 수 있어야 하지만, 기본 종목이 늘어나 빈도는 낮다.

**Independent Test**: 커스텀 운동을 만들면 목록에 생기고 체크된 상태로 "+ 1 운동 추가"가 보이는지 확인한다.

**Acceptance Scenarios**:

1. **Given** 커스텀 운동 추가, **When** 이름(1~60자)·부위·장비를 정해 만들면, **Then** 목록에 추가되고 선택된다.
2. 이름이 비었거나 60자를 넘으면 안내하고 만들지 않는다.

---

### User Story 5 - 기본 종목 확장 (Priority: P1)

사용자는 처음부터 약 90개의 기본 종목(장비별 변형 포함)을 쓸 수 있고, 모두 장비와 자극 부위가 정해져 있으며 텍스트 가이드가 있다. 이미 앱을 쓰던 기기도 업데이트하면 새 종목이 추가된다.

**Why this priority**: 사용자가 직접 요청했고, 필터(US2)가 의미 있으려면 종목이 충분해야 한다.

**Independent Test**: 기존 기록이 있는 기기에서 새 버전을 열면 기록은 그대로이고 "스미스 머신 벤치 프레스" 같은 새 종목이 보이는지 확인한다.

**Acceptance Scenarios**:

1. **Given** 새로 설치, **Then** 기본 종목 약 90개가 있고 모두 장비·자극 부위·가이드가 있다.
2. **Given** 예전 버전(기본 종목 35개)을 쓰던 기기, **When** 업데이트하면, **Then** 새 기본 종목이 추가되고, 사용자가 이름을 바꾸거나 지운 기존 기본 종목은 그대로 둔다.

---

### Edge Cases

- 같은 종목을 선택 화면에서 두 번 누르면 선택이 풀린다(한 번에 같은 종목을 두 번 넣으려면 두 번 추가한다).
- 루틴 종목 50개, 세션 종목 50개 한도를 넘게 고르면 한도까지만 추가하고 몇 개를 못 넣었는지 안내한다.
- 이미 루틴에 있는 종목도 고를 수 있다(같은 종목을 두 번 넣는 것을 허용, 기능 1과 같음).
- 지워진 종목은 목록에 보이지 않는다.
- "자주하는"·"최근"은 완료한 세션만 센다. 기록이 없으면 "아직 기록이 없어요"가 보인다.
- 오프라인에서도 모두 동작한다.
- 320px 화면에서 필터 줄은 가로로 밀어서 본다(페이지 전체가 가로로 넘치지 않음).

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 종목 추가(루틴 편집·루틴 상세·진행 화면)는 전체 화면 종목 선택을 열어야 하며, 여러 종목을 골라 "+ N 운동 추가"로 고른 순서대로 한 번에 추가할 수 있어야 한다.
- **FR-002**: 종목 선택은 이름 검색(공백·대소문자 무시)과 세 줄 필터(분류, 근육 부위, 장비)를 제공해야 하며, 모두 함께 적용되어야 한다.
- **FR-003**: 분류 필터는 전체, 좋아하는(좋아요), 자주하는(완료 세션 사용 횟수 많은 순), 최근(마지막 사용일 최근 순), 커스텀(직접 만든 종목)이어야 한다.
- **FR-004**: 근육 부위 필터는 가슴, 등, 어깨, 삼두, 이두, 전완, 복근, 둔근, 햄스트링, 대퇴사두, 승모, 종아리이며, 종목의 주동근·보조근 중 하나라도 해당하면 보여야 한다.
- **FR-005**: 장비 필터는 맨몸, 덤벨, 바벨, 스미스머신, 머신, 케이블, 밴드, 케틀벨, 유산소, 기타이며, 종목마다 장비가 하나 정해져 있어야 한다.
- **FR-006**: 종목 줄은 좋아요(토글), 이름, 자극 부위(최대 2개), 선택 표시, 더보기를 보여야 한다. 좋아요는 기기 간에 동기화되어야 한다.
- **FR-007**: 더보기는 가이드, 이력, 이름 수정, 삭제(되돌리기 가능)를 제공해야 한다.
- **FR-008**: 선택 초기화, 맨 위로(목록을 내렸을 때), 뒤로(추가 없이 닫기)를 제공해야 한다.
- **FR-009**: 커스텀 운동 추가는 이름(1~60자)·부위·장비를 받아 종목을 만들고 바로 선택해야 한다.
- **FR-010**: 기본 종목을 약 90개로 늘리고, 모든 기본 종목에 장비, 자극 근육, 텍스트 가이드(기능 2 규칙)가 있어야 한다.
- **FR-011**: 기존 기기는 업데이트 시 새 기본 종목을 받아야 하며, 사용자가 고치거나 지운 기본 종목은 바꾸지 않아야 한다. 고치지 않은 기본 종목에는 새 정보(장비)가 반영되어야 한다.
- **FR-012**: 추가 한도(루틴·세션 종목 50개)를 넘는 선택은 한도까지만 추가하고 안내해야 한다.

### Key Entities

- **운동 종목(Exercise)**: 기존 필드에 **장비**(선택, 위 목록)와 **좋아요**(선택, 참/거짓)가 더해진다. 둘 다 동기화된다.
- **근육 부위 그룹**: 필터용 12개 그룹. 각 그룹은 하나 이상의 근육(기능 2의 근육 17종)에 대응한다.
- **종목 사용 통계**: 완료 세션에서 계산하는 사용 횟수와 마지막 사용일(저장하지 않음).

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 종목 5개짜리 루틴을 만들 때 종목 선택을 한 번만 열면 된다(이전에는 5번).
- **SC-002**: 원하는 종목을 검색이나 필터 두 번 이하로 찾을 수 있다.
- **SC-003**: 종목 선택은 90개 목록을 체감 지연 없이(0.5초 이내) 보여 주고, 필터를 바꾸면 즉시 바뀐다.
- **SC-004**: 기본 종목 100%가 장비·자극 근육·가이드를 갖는다.
- **SC-005**: 업데이트 후에도 기존 기록·이름 바꾼 종목이 100% 그대로다.

## Assumptions

- 종목 이미지는 넣지 않는다. 플리크의 "스트레칭" 장비 분류는 해당 기본 종목이 없어 넣지 않는다.
- 자극 부위 표시는 가이드의 주동근을 먼저, 보조근을 다음으로 그룹 이름으로 바꿔 최대 2개 보여 준다. 직접 만든 종목은 가이드 노트의 근육이 있으면 그것을, 없으면 부위로 보여 준다.
- 좋아요는 종목 레코드의 필드라 이름 수정과 동시에 다른 기기에서 고치면 나중 수정이 이긴다(기능 1과 같음).
- 종목 선택에서 루틴 편집처럼 목표 세트 수를 정하지는 않는다(기본 3세트, 편집 화면에서 조절).
