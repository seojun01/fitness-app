# Research: 종목 선택 개편과 기본 종목 확장

각 항목은 결정 / 근거 순서다.

### P1. 선택 화면: 전체 화면 `<dialog>`, 결과는 종목 id 배열
- **결정**: `pickExercises(ctx, { limit? }) → Promise<string[]>`로 바꾼다. 전체 화면 대화상자로 열고, 고른 순서를 지켜 돌려준다. 호출한 쪽(루틴 편집·상세·진행 화면)이 한도까지 넣고 못 넣은 개수를 안내한다.
- **근거**: 화면 이동 대신 대화상자로 열면 호출 화면의 입력·타이머가 그대로다(기능 2 G8과 같은 이유).

### P2. 근육 부위 그룹
- **결정**: 그룹 12개는 가슴(대흉근), 등(광배근·능형근·척추기립근), 어깨(전면·측면·후면 삼각근), 삼두, 이두, 전완, 복근(복직근·복사근), 둔근, 햄스트링, 대퇴사두(대퇴사두근), 승모, 종아리다.
- 기본 종목의 태그는 가이드의 주동근 → 보조근 순서로 그룹으로 바꾸고 중복을 뺀다. 화면에는 앞의 2개만 보이고, 필터는 전부에 대해 적용한다.
- 직접 만든 종목은 노트의 근육이 있으면 그것을 쓰고, 없으면 부위로 정한다(하체 → 대퇴사두·둔근·햄스트링·종아리, 팔 → 이두·삼두·전완, 코어 → 복근, 유산소·기타 → 없음).
- **근거**: 기능 2의 근육 데이터를 다시 써서 따로 관리할 표가 생기지 않는다.

### P3. 장비와 좋아요는 종목 레코드의 선택 필드
- **결정**: `equipment`는 10개 값 중 하나, `favorite`는 참/거짓이다. 둘 다 없으면 장비는 기본 종목 목록에서 같은 id를 찾고, 없으면 `bodyweight ? 'bodyweight' : 'other'`로 정한다. 좋아요는 없으면 거짓이다.
- **근거**: 새 레코드 종류 없이 동기화된다. 좋아요를 누르면 기본 종목도 실제 버전이 되어 올라간다(메모와 같은 방식).

### P4. 기본 종목 세트 업그레이드
- **결정**: `SEED_SET = 2`이고, 메타 `seedSet`에 기기가 받은 세트 번호를 둔다. 번호가 낮으면 한 트랜잭션에서 두 가지를 한다.
  1. 없는 기본 종목을 넣는다.
  2. 시드 버전 그대로인(사용자가 고치지 않은) 기본 종목을 새 내용(장비)으로 바꾼다.
- 사용자가 고친 기본 종목(실제 버전)이나 지운 종목(툼스톤)은 건드리지 않는다. 장비는 P3의 기본값 규칙으로 보인다.
- **근거**: 기존 `seeded` 플래그만으로는 새 종목이 들어가지 않는다. 고친 종목을 덮어쓰면 데이터 소유권 원칙에 어긋난다.

### P5. 자주하는·최근
- **결정**: 완료 세션(삭제 안 됨)에서 종목별 사용 세션 수와 마지막 `endedAt`을 한 번 계산한다. "자주하는"은 사용 횟수 내림차순(1회 이상), "최근"은 마지막 사용일 내림차순이다.
